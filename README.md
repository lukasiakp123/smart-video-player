# Smart Video Player (Vanilla JS)

Mini aplikacja prezentująca wykorzystanie nowoczesnych Web API:
- Intersection Observer API
- Picture-in-Picture API
- Media Session API
- Canvas API

## Funkcje
- Lazy loading wideo (200px przed viewportem)
- Automatyczny Picture-in-Picture przy scrollu
- Integracja z systemowymi kontrolkami multimediów
- Snapshot aktualnej klatki (WebP)
- Media Session API
- Obsługa błędów
- Testy modułów

## Instalacja
```bash
npm install
npm test
